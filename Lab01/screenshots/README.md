# Screenshots

These are intentionally **not** generated by `run_lab.sh`. A screenshot is
evidence that *you* ran the tool on *your* machine, so fabricating them would
defeat the purpose. Capture them yourself with the commands below.

The corresponding plain-text captures are already saved in `Lab01/` (see the
"saved output" column), so the screenshots are confirmation, not the only
record.

## Note on screenshot 10

`perf stat` on this machine reports `<not supported>` for every hardware counter
(cycles, instructions, cache references/misses, branch misses) because the WSL2
kernel exposes no virtual PMU. **That output is itself the result** — capture it
as-is; screenshot 11 (`perf_probe`) shows the underlying cause at the syscall
level. See README §7.

To capture real hardware counters, run screenshot 10 on native, non-virtualised
Linux.
